
This is a **file-based Speech Recognition application** built with Python and Streamlit. It allows users to upload audio files and transcribe speech into text using different speech recognition APIs. This version does **not require a microphone** or PyAudio, making it easy to run on any machine.  

## Features

- Upload `.wav` or `.flac` audio files for transcription.
- Choose the speech recognition API: **Google** or **Sphinx**.
- Select the language of the spoken content (e.g., `en-US`, `fr-FR`, `es-ES`).
- View the transcribed text directly in the web interface.
- Save the transcription to a text file with one click.
- Fully web-based interface powered by **Streamlit**.
